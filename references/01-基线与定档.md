# 基线与定档（v1.0）

这份文档回答三个问题：**默认阈值从哪来、哪些能信、怎么用自己的样本换一套。**

---

## 一、阈值的三个来源（重要，别混用）

| 标记 | 含义 | 能不能直接当验收线 |
|---|---|---|
| **实测** | 在人类中文语料上量出来的分位数（采样方式见下） | 能，但要看清语料体裁 |
| **经验档** | 从写作实践里定出来的合理区间，未做大样本量化 | 只能起步，务必用自己文体的样本校准 |
| **零频锚** | 人类语料里出现次数≈0 的形态 | 能，这类项最硬（如 ASCII 引号、对仗收束） |

**采样基础（`实测` 项的来源）**：11 部中文叙事作品全文，取 24 份切片约 23 万字；区间推导方式为 `[P25 − 0.5×IQR, P75 + 0.5×IQR]` 作验收带，`[P25, P75]` 作改写瞄准带。

**已知局限**：原始语料是长篇叙事作品，因此句长、段长、虚词密度这些**语言底层指标**可迁移到同属叙事/随笔的文体；而对话占比、人名密度、粗口密度这类**内容指标**不可迁移，本版已归入"仅 narr 且对白充分时启用"或直接删除。论说与公文档位的多数项属 `经验档`，**用前必须校准**。

---

## 二、三档默认值

### 1. 节奏与篇幅（最硬的四项）

下表"验收线/瞄准线"与 `scripts/lint.py` 内置默认值一致：超出验收线为 FAIL，只在瞄准线外为 WARN。

| 指标 | narr 叙事 | args 论说 | offi 公文 | 来源 |
|---|---|---|---|---|
| 段均字数（上限） | 验收 ≤70，瞄准 ≤45 | 验收 ≤90，瞄准 ≤60 | 验收 ≤120，瞄准 ≤85 | narr 实测 / 其余经验 |
| 句长均值（下限） | 验收 ≥18.0，瞄准 ≥20.5 | 验收 ≥20，瞄准 ≥24 | 不查 | narr 实测 |
| 句长标准差（下限） | 验收 ≥10.0，瞄准 ≥13.0 | 验收 ≥8.0，瞄准 ≥11.0 | 不查 | narr 实测（均匀体 11.7） |
| 单句成段占比（下限） | 验收 ≥0.15，瞄准 ≥0.25 | 验收 ≥0.10，瞄准 ≥0.18 | 验收 ≥0.08，瞄准 ≥0.15 | narr 实测 |
| ≤15 字短段占比（下限） | 验收 ≥0.10，瞄准 ≥0.15 | 验收 ≥0.06，瞄准 ≥0.10 | 不查 | narr 实测 |
| 逗号/句（下限） | 验收 ≥0.80，瞄准 ≥1.15 | 验收 ≥1.05，瞄准 ≥1.15 | 验收 ≥1.0，瞄准 ≥1.1 | narr 实测 |
| 段长变异系数（下限） | 验收 ≥0.45，瞄准 ≥0.60 | 验收 ≥0.40，瞄准 ≥0.55 | 不查 | narr 实测 |

**为什么这四项最重要**：AI 的文本在"长短分布"上是坍缩的——句长集中在均值附近、段落长度接近、每段句数接近。人不是。这一项比任何用词都难伪装，也是唯一在你改完词以后还会持续暴露的东西。

### 2. 字符与标点

| 指标 | 线 | 来源 |
|---|---|---|
| ASCII 引号 / 单引号 | 0 | 零频锚 |
| `...`（三点省略号） | 0，统一"……" | 零频锚 |
| 破折号 | 验收 ≤10/万字，瞄准 ≤5，且只留真打断 | 实测（人类方差大，只抓堆积） |
| 感叹号 | narr 验收 ≤68/万字，瞄准 ≤45 | 实测 |
| 问号 | narr 验收 ≥22/万字，瞄准 ≥30 | 实测 |

### 3. 词法密度（每万字）

| 词 | 人类 P25 | 中位 | P75 | 内置线（narr） |
|---|---|---|---|---|
| 就 | 39.9 | 55.2 | 64.0 | ≥20（瞄准 ≥30） |
| 是 | 121.5 | 135.4 | 163.2 | ≥70（瞄准 ≥95） |
| 才 | 9.9 | 12.5 | 15.3 | ≥3（瞄准 ≥6） |
| 还 | 23.2 | 34.0 | 38.0 | ≤55（瞄准 ≤38） |
| 都 | — | 32.8 | — | 不查（仅作人工参考） |
| 把 | 9.8 | 15.1 | 19.9 | ≤32（瞄准 ≤22） |
| 往 | 2.0 | 4.1 | 6.3 | ≤16（瞄准 ≤9） |
| 被 | 9.3 | 21.1 | 26.6 | ≥4（瞄准 ≥9） |
| 向 | 10.1 | 11.6 | 18.0 | ≥3（瞄准 ≥6） |
| 对 | 24.8 | 27.4 | 33.9 | ≥13（瞄准 ≥20） |
| 让 | 11.2 | 15.5 | 20.2 | ≥4（瞄准 ≥8） |
| 给 | 9.5 | 11.6 | 19.4 | ≥3（瞄准 ≥7） |
| 地 | 17.6 | 29.0 | 49.4 | ≥0（瞄准 ≥8） |
| 比喻词（像/仿佛/如同/似的/宛如） | — | 16.9 | 22.8 | ≤20（瞄准 ≤16.5） |

**为什么"线"普遍比人类 P25 松**：这些是**护栏**不是**目标**。AI 的通病是极端化（把连词清到 0、把"地"全删），护栏设在 P25 外侧，是为了让正常人的稿子不误伤；想往人类中位靠，看"瞄准"列。

**注意"往"和"向"是反向的**：人类"向"多（中位 11.6）、"往"少（中位 4.1）。写成"往走廊那头看了一眼 / 朝走廊看了一眼"才对，"往"堆到 20 以上是机器指纹。

**"地"的密度为什么重要**：AI 倾向把状语写全（`认真地`、`缓慢地`、`轻轻地`）。人类中文大量省略"地"。低于 8/万字（瞄准线），通常意味着你在用形容词思维写句子；高于人类 P75（49.4）则是另一种机械感。

### 4. 内容层（新增，通用版重点）

| 指标 | 线 | 来源 |
|---|---|---|
| `不是X，而是Y` | ≤2/千字 | 经验档（AI 第一高频句式，目测远超人类） |
| 抽象行话（赋能/抓手/闭环/维度/底层逻辑/生态/范式） | ≤2/千字 | 经验档 |
| 精确数字 | ≤3/千字，且至少一个兑现 | 经验档 |
| 元注释（本文认为/接下来/如前述） | ≤8% | 经验档 |
| 总结归纳句（总之/归根结底/说到底） | ≤2/篇，且不在末段 | 经验档 |
| 假互动（你有没有发现/让我们一起/我们都知道） | 0 | 零频锚（人类正式书面语近零频） |

## 三、怎么用你自己的样本校准（推荐做法）

**原则：先量人类，再定规则；定了规则，别当目标。**

### 步骤

1. 找 3-5 篇**同体裁、同平台、你认可**的人类文章（不是名著，是"这类文章里写得好的"）。放在一个目录里，`.md` 或 `.txt`，UTF-8。
2. 跑校准：

```bash
python scripts/lint.py --calibrate 语料目录/ --genre args --save-profile my_profile.json
```

输出会给出每项指标的 P25 / 中位 / P75，并生成一份 profile。瞄准带取 `[P25, P75]`，验收带取 `[P25 − 0.5×IQR, P75 + 0.5×IQR]`。
3. 用这份 profile 检稿：

```bash
python scripts/lint.py 稿件.md --profile my_profile.json
```

4. 如果某个指标在你的样本里方差极大（P25 与 P75 相差 3 倍以上），说明它不构成这一文体的稳定特征，**从 profile 里删掉**，别拿它当尺子。

### 三条禁令

1. **不许清到极值**。连词被清到 0.6%（人类 5.4%）、破折号堆到 14.4（人类中位 2.5），都是实测翻车案例。
2. **比值型指标必须等长比较**。字种比就因为长度混淆翻过车：人类样本 9700 字、AI 稿 2700 字，看起来"人类 0.128 vs AI 0.214"，等长 2500 字窗口复测后方向完全相反。
3. **样本量 <5000 字不要生成 profile**。分位数在小样本上没有意义，会得到一套"正好适合这一篇"的假阈值。

## 四、主谓宾完整句（防断片）

| | 数值 |
|---|---|
| 人类叙事语料 8 篇切片 | 60.8%–75.1%，中位 68.0% |
| 判定 | 70-90% PASS；60-70% WARN；>90% WARN（过度完整）；<60% FAIL |

**这一项是用来防"断片"的，不是要求每句都写成"主语+动词+宾语"。**汉语天然允许零指代、承前省略、话题句；硬压到 95% 会写成一个模子，那本身是另一种 AI 形态。

论说文/公文因为长句多、连接词多，这一项通常自然在 70-85%，不需要特别处理。
