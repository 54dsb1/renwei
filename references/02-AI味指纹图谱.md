# AI 味指纹图谱（v1.0）

这份文档不讲怎么改，讲**为什么读起来像 AI**。诊断清楚了，改法在 CORE 里对应着取。

先给一个总纲：

> **AI 的文本是"没有作者的文本"。** 它每句话都在传递信息，没有一句在浪费时间；它永远正确，永远得体，永远知道下一句该说什么。人写字不是这样——人会跑题、会重复、会judge、会写错、会突然不想写了。

六个层面，从上到下越来越难伪装。

---

## 一、语义层：每个字都在工作

**症状**：删掉任何一句，意思都缺一块。全文没有一句废话。

**为什么会这样**：模型被训练成"最大化信息密度"，冗余在损失函数里是负分。

**人的反面**：人类的文本里大约三分之一不传递新信息——寒暄、复述、自我修正、口头禅、跑一句题、评价一下刚说的事。

```
AI：本次会议明确了三项重点：一是……二是……三是……
人：会开了一个半小时，前三十分钟在确认上次的会到底定了什么。
```

**对应规则**：CORE §2.6 人味配给 O1-O9。

---

## 二、结构层：对称、预告、总结

**症状**（四个高频形态）：

| 形态 | 长相 |
|---|---|
| 总-分-总 | 开头说"将从三个方面展开"，结尾说"综上" |
| 三点式 | 任何话题都能整齐切成三点，且三点等长 |
| 首尾呼应 | 开头那个比喻，结尾一定要再用一次 |
| 递进包装 | "不仅……而且……更重要的是……" 层层加码 |

**为什么会这样**：这是"好作文"的训练痕迹。模型的语料里，被标注为好文本的中文，大量来自教材、范文、公文、媒体评论——这些文本的结构是被规范化过的。

**人的反面**：人写东西的结构是"想到哪写到哪，最后临时找了个收尾"。所以人的文章常常是：两点半、有偏重、结尾没说完、中间插了一段不搭界的。

```
AI：首先，要建立机制。其次，要压实责任。最后，要形成闭环。
人：机制这事去年就提过，责任压在谁头上一直没定。闭环？现在连谁在管都没弄清楚。
```

**对应规则**：CORE §2.2 结尾、§2.3 段落呼吸、§1 结构位。

---

## 三、节奏层：匀速

这是**最硬的指纹**，也是最难改的。三个指标同时看：

| 指标 | AI 的样子 | 人的样子 |
|---|---|---|
| 句长标准差 | 8-11（都差不多长） | 13-16（忽长忽短） |
| 段均字数 | 均匀，±3 字以内 | 差距能到 3 倍 |
| 每段句数 | 2-3 句，很整齐 | 1 句到 8 句都有 |

**为什么会这样**：生成是逐 token 的概率最大化，长句和极短句都是低概率事件，于是被系统性削平。

**怎么读出来**：把文章竖着看右边缘。如果右边是一条整齐的线，就是机器。

**人的反面**：人会写一句 40 字的长句（想到一半没想清楚，先连着说下去），紧接着写一句 4 字的（"算了。"），然后一整段只有一句话。

```
AI：数字化转型是企业提升竞争力的重要途径。企业应当加强数据治理。同时需要培养数字化人才。
人：数字化这事，说了三年。钱花了不少，系统换了两套。到现在报销还得打印。
```

**对应规则**：CORE §1 节奏组、§2.3。

---

## 四、用词层：四类词

| 类型 | 例子 | 为什么像 AI |
|---|---|---|
| 抽象名词 | 赋能、抓手、闭环、维度、生态、范式、颗粒度、底层逻辑 | 名词化让句子"看起来有内容"，实际不指向任何具体事物 |
| 书面连接词 | 因此、然而、此外、与此同时、综上所述、值得注意的是 | 密度过高，人说话不会每句都带逻辑连接 |
| 评价性形容词 | 深刻的、重要的、显著的、丰富的、独特的 | 替读者下判断，且几乎不带信息 |
| 万能动词 | 进行、开展、实现、推动、打造、助力 | 动词被名词化后又配一个空动词，动作消失了 |

**测试方法**：把每个抽象名词换成"这个东西到底是什么"，答不上来的删掉。

```
AI：通过打造闭环生态，实现对用户全生命周期的深度赋能。
人：用户从注册到流失，中间的每一步我们都有人盯。以前没人管第三步。
```

**对应规则**：CORE §1 内容-术语、§2.5。

---

## 五、语用层：安全写作

**症状**（这一层最像"人"的分水岭）：

1. **不敢下判断**：所有观点都加"在一定程度上""某种意义上""因人而异"。
2. **不敢犯错**：不写自己不确定的事，不写"我猜"，不写"我可能记错了"。
3. **不敢跑题**：所有段落都紧扣主题，没有一句闲话。
4. **不敢有情绪**：遇到该生气的事，写成"这引发了一些讨论"。
5. **不敢有偏好**：`A 有 A 的好处，B 有 B 的好处`——这不是观点，是免责声明。

**人的反面**：人会偏心、会不耐烦、会说"我就是不喜欢这个人，说不上为什么"。

```
AI：对于该方案，业内存在不同看法，需要结合具体情况综合判断。
人：我一开始也觉得这方案行。后来发现他们连成本口径都没统一，就算了。
```

**对应规则**：CORE §3 第四问（反驳测试）、§2.6 O4/O5。

---

## 六、视角层：谁在说话

**症状**：全文没有"一个人"在说话，只有一个"位置"在说话。

| 表现 | 说明 |
|---|---|
| 无身体 | 叙述者不饿、不困、不冷，不需要坐下 |
| 全知 | 知道所有人的动机，且都能解释清楚 |
| 无立场 | 描述一件事时，同时给出所有方面的合理性 |
| 无时间 | 没有"写这段话的时候"的处境 |

**为什么会这样**：模型没有身体、没有处境、没有偏好，它只有一个"平均视角"。

**人的反面**：人写字是有处境的——在通勤地铁上写、被领导骂完写、半夜睡不着写。这个处境会漏进文本：一句话的急躁、一个比喻的来源、突然的一句自嘲。

```
AI：面对挑战，我们应当保持理性，积极应对。
人：这话我在会上没敢说。说了也没用，但不说是真的难受。
```

**对应规则**：CORE §2.1 开头、§2.6 O6/O9、§3 第五问。

---

## 七、诊断速查：读到什么，改哪一层

| 你读到的感觉 | 大概率是哪层 | 先改什么 |
|---|---|---|
| "很顺，但读完什么都没记住" | 语义层（无冗余、无具体） | 加 4-6 条人味配给；把抽象名词换成一件事 |
| "像汇报材料 / 像公众号模板" | 结构层（对称、预告、总结） | 拆掉总-分-总；末段删掉；段落打散 |
| "读着累 / 读着想睡" | 节奏层（匀速） | 句长 SD、段长错落、拆出单句成段 |
| "每个词都对，但不像人话" | 用词层 | 术语清零；连接词删一半；动词还原 |
| "说得都对，但没观点" | 语用层 | 加一处可被反驳的判断；删掉所有"一定程度上" |
| "不知道是谁在写" | 视角层 | 给一个身体动作、一句处境、一句自嘲 |

---

## 八、一个反直觉的提醒

**不要用"更像人"的技巧去覆盖"AI 味"。** 这是最常见的失败方式：把每段都加一个手部动作、每段结尾都留一句余味、每 300 字插一个"我愣了一下"——这些技巧本身会形成新的、更明显的指纹，因为它同样"每个字都在工作"，只不过工作的方向变了。

真正的分界线只有一条：**这段文字里，有没有一处是"不为了读者"写的。**
